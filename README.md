# AI 약속 마을

초등 1~3학년을 위한 AI 윤리 수업 사이트예요. 4개 단원과 교사용 자료실이 있어요.

- 1단원 진짜가짜 광장: 딥페이크·허위정보
- 2단원 비밀 금고 집: 개인정보·프라이버시
- 3단원 모두의 놀이터: 편향·공정성
- 4단원 솔직 도서관: 저작권·AI 활용 정직성
- 낱말 사전, 우리의 약속 모아보기, 소리 읽어 주기, 선생님 안내

## 파일 구성
- `index.html` 화면 틀과 스타일
- `units.js` 단원 데이터 (새 단원은 여기에 항목을 더해요)
- `app.js` 화면 로직
- `resources/` 1단원 교사용 자료(인쇄용 웹 페이지)
- `resource.html` 2~4단원 교사용 자료를 만들어 주는 페이지 (예: resource.html?u=2&t=plan)
- `images/` 이미지 (intro-person.jpg를 올리면 1단원 도입 화면에 우선 표시돼요)
- `docs/` 기획·디자인 요약, `CLAUDE.md` 작업 규칙, `SETUP.md` 컴퓨터 준비
