# 기획 요약 (기획서 v0.6 기준)

- **사이트 이름**: AI 약속 마을
- **대상**: 초등 저학년(1~3학년), 수업용(교사가 전자칠판에 띄워 함께 봄)
- **운영**: 개인 교사. 교과 연계 없는 자유 주제 수업용
- **수업 분량**: 단원당 1차시(40분) = 도착 5분 / 배우기 12분 / 체험 12분 / 퀴즈 7분 / 약속 4분
- **참고 사이트**: https://ai-basic-act-kids.vercel.app/ (인공지능기본법 제31조 AI 표시 의무)
- **단원**: 1. 진짜가짜 광장(딥페이크·허위정보) 2. 비밀 금고 집(개인정보·프라이버시) 3. 모두의 놀이터(편향·공정성) 4. 솔직 도서관(저작권·AI 활용 정직성)
- **공통 틀**: 학습 목표 → 도착 → 배우기 → 체험 → 퀴즈 → 약속 → 낱말 사전. 선생님 안내는 별도 버튼.
- **설계 원칙**: 읽기 부담 최소화(용어는 처음 나오는 곳에서 바로 풀이), 한 화면 한 개념, 조작형 학습, 행동 약속으로 마무리, 개인정보 수집 최소화, 교사가 바로 쓰는 자료.
- **교사용 자료실**: 지도안, 학생 활동지, 평가 질문·체크리스트. 학부모 안내문과 Word 파일은 이번 범위에서 제외.
- **제작 순서**: 1단원 → 2 → 3 → 4 순차. 작업은 GitHub 이슈로 관리해요.

## 진행 현황 (작업이 끝날 때마다 갱신)
- 기획 완료 / 디자인 확정 / 1단원 구현과 자료실(1단원 3종) 완료, 저장소 업로드 진행 중(#11)
- 미착수: 2~4단원, 낱말 사전·약속 모아보기 페이지, 소리 읽어주기, 2~4단원 교사용 자료
