# 디자인 요약 (디자인 문서 v0.2 기준)

- **스타일**: 선명한 현대 앱 스타일. 연한 하늘색 바탕에 흰 카드, 부드러운 그림자. 아이보리·명조체 같은 차분한 책 느낌은 쓰지 않아요.
- **글꼴**: Noto Sans KR 하나. 제목 900, 강조 700, 본문 400. 본문 18~26px, 제목 28~50px, 버튼 높이 64~72px, 줄 간격 1.55.
- **색**: 배경 #EEF3FF(다크 #0B1330), 카드 #FFFFFF(다크 #16224A), 글자 #0B1B3A(다크 #EAF0FF), 주 버튼 #2F55E8
- **단원 색**: 1 코랄 #E8492C / 2 파랑 #2F55E8 / 3 민트 #0B7A55 / 4 보라 #7B3FE4 / 정답 #0B8F63 / 강조 노랑 #FFD43B
- **캐릭터**: 약속이(노란 동그란 얼굴), 말풍선으로 설명을 이끌어요.
- **홈**: 왼쪽 남색 패널 + 오른쪽 단원 타일 4개. **단원 화면**: 위쪽 5단계 막대, 큰 카드, 아래 이전/다음 큰 버튼.
- **접근성**: 키보드·터치·마우스 모두 가능, 색에만 의존하지 않기(정답은 글자와 체크도), 움직임 줄이기 지원, 밝은/어두운 모드.
