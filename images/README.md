# 이미지 폴더

수업 화면에 쓰는 이미지를 넣는 곳이에요.

## intro-person.jpg (1단원 도입 화면)
- “이 그림 속 사람은 진짜일까요?” 화면에 보여 주는 사람 이미지예요.
- 파일 이름은 **intro-person.jpg** 로 해 주세요. (이 파일이 없으면 기본 일러스트가 보여요.)
- 가로로 긴 이미지(16:9 정도)가 가장 잘 맞아요.

## 이미지를 고를 때 꼭 지켜 주세요
- AI로 만든 **실존하지 않는 인물**의 이미지를 써요. 실제 사람의 사진은 초상권·저작권 문제가 있고, 딥페이크 수업에서 실제 인물의 얼굴을 쓰는 것도 적절하지 않아요.
- 화면의 설명이 “사실은 AI가 만든 그림이야”라고 말하므로, 정말 AI로 만든 이미지여야 해요.
- 실제 학생·교사·유명인의 얼굴이나 닮은 얼굴은 쓰지 않아요.
- 이미지를 만든 AI 서비스의 이용 약관에서 수업 사용이 허용되는지 확인해 주세요.
